Figure 1 Source Code

This page documents the simulation code used to create Figure 1 in Choosing and Evaluating Randomization Procedures in Clinical Trials: A Tutorial. The figure compares treatment allocation imbalance and unpredictability for complete and restricted randomization procedures in a single-center trial with n = 50.

Download the R source code, download the plotted summary table, or view the regenerated figure below.

How the Figure Is Constructed

For each randomization procedure, the script simulates M = 1000 independent allocation sequences. Each sequence is summarized once for the proportion of allocations where the absolute running treatment-count imbalance is at least 2, and once for unpredictability, defined as 1 - correct guess probability under the Blackwell-Hodges convergence guessing strategy.

The plotted coordinates are means of these replicate-level summaries. Monte Carlo standard errors are estimated across the independent sequences as sd(Z) / sqrt(M). The horizontal bars show uncertainty in the imbalance coordinate; the vertical bars show uncertainty in the unpredictability coordinate. Allocation prefixes from the same sequence are not treated as independent observations.

Interpretation

The Monte Carlo intervals quantify simulation error under this specific sample size and set of procedure parameters. They do not represent sensitivity to block size, biased-coin probability, maximum tolerated imbalance, sample size, or alternative guessing strategies.
